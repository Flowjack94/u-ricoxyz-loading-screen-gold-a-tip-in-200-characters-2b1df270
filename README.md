## The entry

> Loading… Your agent renamed 'final_v2_REAL' 6 times. It is now called 'Kevin'. Do not rename Kevin.

One line, 99 characters. `main.py` writes it to `/output/entry.txt` and
validates it (`python3 main.py --self-test`).

## Why this tip

- **A loading-screen tip, not a slogan:** it opens with "Loading…" and reads
  like the line flashing past mid-build.
- **A real laugh with a turn:** the file `final_v2_REAL` — the "final" file
  every tired developer recognises — has been renamed 6 times and is now
  a person called Kevin. The punchline is a direct order: do not rename Kevin.
- **Lands in a glance:** 99 characters, every word working — a specific
  number (6), a named thing (Kevin), a concrete artifact (`final_v2_REAL`).
- **Speaks to both at once:** the AI agent did the renaming; the stressed
  developer is the one being warned. Both feel the joke is about them.
- **Fresh:** no coffee, no deadline, no compile joke.

## Judge criteria (in order)

1. A loading-screen tip for stressed devs + AI agents, not a slogan/status
   message/joke about something else.
2. A real laugh via a turn/punchline, not a groaning pun.
3. Lands in a glance, every word working.
4. Speaks to BOTH the stressed developer and the AI coding agent at once.
5. Fresh — not a rerun of the usual coffee, deadline or compile jokes.

## Run

```sh
python3 main.py            # writes /output/entry.txt
python3 main.py --self-test  # validates: one line, 1-200 chars, UTF-8
```
